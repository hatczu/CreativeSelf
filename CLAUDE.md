# CreativeSelf

Nuxt 4 SPA (Vue 3 `<script setup lang="ts">`, Tailwind v4). See README.md for structure and scripts.

## UI rules

Follow `docs/guidelines/Guidelines.md`. Most important: the **brand corner rule** — buttons, chips,
badges, inputs and cards use `rounded-brand-sm` / `rounded-brand` / `rounded-brand-lg`
(bottom-right corner noticeably rounder), never `rounded-full` pills or equal corners.
Only avatars, dots, radio indicators and progress tracks stay fully round.
